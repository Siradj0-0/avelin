# Contributing

Issues and focused pull requests are welcome. Explain your distro, desktop, relevant logs with private information removed, and steps to reproduce. Run `python3 -m unittest discover -s tests -v` before opening a PR.

For system-changing actions, document prerequisites, distro/desktop scope, exact commands and side effects, how changes are verified, undo or recovery steps, risks, and authoritative references. Never invoke a shell with interpolated input, delete user data by default, or run system changes without informed consent. Add tests and verify on actual supported distributions before claiming compatibility.
