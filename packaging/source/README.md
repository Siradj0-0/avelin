# Experimental source archive builder

Build a source-only tarball from a **full commit SHA** in an existing checkout:

```sh
mkdir -p /tmp/avelin-source-output
python3 packaging/source/build.py "$(git rev-parse HEAD)" /tmp/avelin-source-output
python3 -m unittest discover -s packaging/source -v
```

The archive uses the version in that commit, not the working tree. Uncommitted and untracked files are excluded; Git archive attributes apply. The output must not already exist. With the same Git and Python environment, the same commit produces the same compressed bytes. Reproducibility across different tool versions and independent build environments has not been established.

The printed SHA-256 identifies the generated bytes; it does **not** authenticate them. This builder neither creates a GitHub Release nor signs, publishes, installs or tests the archive on a target distro. Before a release, validate the actual archive and release commit, verify provenance, and follow the project's release policy.
